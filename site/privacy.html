JSONX Privacy Notes

Last updated July 24, 2026.

What the site handles

The public JSONX site serves documentation, install instructions, and a browser demo. The fixture and paste modes run in the browser. Bring-your-own endpoint mode sends the prompt you enter to the endpoint URL you provide.

Renderer app

The JSONX renderer app is designed to validate a JSONX payload and return structured content for rendering. It does not need user accounts, a database, or stored API credentials. Hosting providers may keep standard access logs for operating the service.

Credentials

Do not enter API keys into the public demo unless you are calling your own endpoint and understand how that endpoint handles credentials. The JSONX site should not store model API keys.

Contact

Use GitHub Issues for project questions, bug reports, and support requests.
